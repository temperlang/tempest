# Release notes

What changed for Temper's users, release by release. 🚨 marks a
breaking change, and 🆕 a new feature.

- [Unreleased](unreleased.md): changes since 0.6.0
- [0.6.0](0.6.0.md) (2025-12-30): `=>` for block lambdas, infix
  `throws`, `Int32` and `Int64`, new multi-line strings, and open
  source licensing
- [0.5.0](0.5.0.md)
- [0.4.0](0.4.0.md)
- [0.3.0](0.3.0.md)
- [0.2.0](0.2.0.md)
- [0.0.1](0.0.1.md)

These are Temper's release notes, from its earlier releases' repository,
where each release gathered the notes written since the last. Release
notes keep the syntax of their time, so their examples aren't checked.

## Writing a release note

A change users would notice gets a note under "Unreleased": a `##`
heading that reads well in a list (start it with 🚨 for a breaking
change, or 🆕 for a new feature), a short explanation, and an example,
plus a line in the list at the top of [unreleased.md](unreleased.md).
At a release, the unreleased notes move to a new `VERSION.md`, with the
version's heading.
